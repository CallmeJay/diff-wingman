# 第一版范围与验收

用户授权：按讨论方案开发源码 Review Helper 第一版，并通过本机 Codex 的订阅登录生成导读。

| 用户需求 / 已接受方案  | 目标对象与允许动作                 | 保持边界                                                        | 验收                                      |
| ---------------------- | ---------------------------------- | --------------------------------------------------------------- | ----------------------------------------- |
| 选择 Git 版本查看 diff | 本地仓库的两个 commit 端点         | 不 checkout、不改 index、不写被审查仓库；工作区未提交内容不计入 | 真实 Git fixture，修改工作区后快照仍一致  |
| 源码上下文             | 变更函数、局部依赖、引用候选、测试 | 静态匹配不冒充完整调用链；未覆盖内容明确显示                    | 引用片段与 commit 中内容对应              |
| Codex 订阅 AI 导读     | 官方 codex exec；ChatGPT 登录      | 不读取或复制 Token，不切换付费 API；用户点生成才调用            | 结构化输出、取消、登录失败及真实 CLI 冒烟 |
| 带源码引用的业务导读   | 阅读分组、行为前后对照、问题       | 不宣布代码安全或审查通过；引用有效不代表解释已证实              | 非法引用、重复或遗漏 change ID 被拒绝     |
| 追问及笔记             | 指定快照和分组                     | 不跨版本继承确认，刷新可恢复本地结果                            | 同快照持久化，不同快照隔离                |

复用：Git、Monaco、Babel、React、Zod；现有 functional-code-review 是独立审查技能，不提供本工具所需的 Web/CLI 适配层，因此新建独立项目。

首版只支持 commit 到 commit；本地调用不表示模型离线运行。导读上下文会经官方 Codex 发往其服务。测试源码不等于测试已执行。暂不实现自动修复、自动批准、自动提交、公共托管、多用户和 Claude 接入。

数据与进程边界：只监听 127.0.0.1；API 使用同源校验和运行期随机令牌；Git 和 Codex 使用参数数组调用。分析数据存于项目 .review-helper/（可通过启动参数改目录），不写入被审查仓库。源码模式不明、文件过大、二进制或解析失败均显式报告。
