# v0.0.11 验收记录

开发基线：`main` 的 `9f9c528`。本轮只实施 v0.0.11；验收数据来自独立的临时 Git 仓库及本地数据目录，没有使用用户现有的审查记录；验收后已清理临时样本与本地服务。

## 已验证

- `pnpm build` 通过，包括 TypeScript、Vite 和服务端编译；Vite 保留既有的大 chunk 提示。
- `pnpm check:v8` 的 5 个用例和 `pnpm check:v3` 的 3 个用例通过，覆盖固定来源的逐块解释、人工依据、旧记录待重核、报告边界和源码位置。默认沙箱内的 HTTP 用例曾因本地监听权限报 `EPERM`，在允许本机端口的环境重跑通过。
- 浏览器使用 105 个文件、105 处真实 Git 变更的隔离快照；导读将 104 处归类、1 处列为未分析。样本另有 2 处当前解释、1 处有依据的逐块“已核实”、1 处旧理解待重核，其他归类变更没有逐块解释。
- 在 1280 × 720 CSS 视口，矩阵宽面板约 1020px，105 行均在内部滚动。打开时自动定位第 66 处当前行；滚动离开后“定位当前变更”可再次找回。关闭按钮和 Escape 均保留原文件与 hunk；点击矩阵行则跳到对应文件和 hunk。760px 窄窗口下三种退出方式还会把代码区带回可见视口并恢复焦点。
- 点击未分析行时，代码区不再错误保留上一功能高亮；点击已归类行时功能高亮恢复。矩阵分别显示“已解释 2/105”“逐块未生成”“阅读路线未分析”“已核实”和“待重核”，与样本状态一致。
- 在 618px 和 760px CSS 视口，矩阵行改为纵向字段卡片，未出现矩阵或页面横向溢出。报告按钮旁明确导出范围；在审查未完成时成功导出，预览包含未审查判断、未分析变更和“不代表自动审查通过”说明。

## 边界与未验证项

- 导读与逐块解释由隔离样本写入本地数据目录；未调用真实 Codex，也未复验模型对复杂 diff 的归类质量。
- 报告正文和服务端接口未改。现有 Markdown 不包含文件、hunk、逐块理解状态；页面入口已说明这一限制。未在真实用户旧评论、真实 GitLab MR 或桌面安装包中重放。
- 本轮没有准备 Git push，按项目规则未执行完整 `pnpm test`；本记录不代表发布或生产验收。
