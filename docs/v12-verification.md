# v0.0.12 验收记录

开发基线：`main` 的 `22bdcdb`。本轮使用独立临时 Git 仓库、临时审查数据目录和模拟 GitLab 响应；未使用用户原有审查记录、凭证或真实私有 MR。知识库 `ui2code@82217ad` 已核对与 upstream 一致。

## 已验证

- `pnpm build` 通过 TypeScript、Vite 和服务端编译；Vite 保留既有大 chunk 提示。`pnpm check:v4` 5/5、`pnpm check:v5` 2/2、`pnpm check:v8` 5/5 通过，覆盖原有验证执行、GitLab 只读导入与符号关系契约。
- 浏览器使用 4 个真实 Git 变更和模拟导读的 128 条判断。默认仅列当前 hunk 的 32 条待核对判断；切换到“全部判断”后按标题搜索到目标项。切换功能、范围以及搜索无结果时，已选判断、触发条件和预期结果仍保留。
- 样本目标提交没有检查脚本；界面说明原因，运行按钮保持禁用。双击源码中的无法解析标识符后，后端错误显示在原提示条；重新选择有效标识符后错误清除，影响链正常打开并标为“精确符号引用”。
- 模拟 GitLab 无权读取 MR 与本地缺少 MR 提交两种失败；错误均在导入表单旁显示，并分别提示核对只读 Host/Token 与自行获取本地提交。约 391px、562px 与 691px CSS 视口下页面未横向溢出。

## 边界与未验证项

- 导读由隔离样本写入，不评估真实 Codex 生成质量；GitLab 响应为模拟数据，不代表真实私有 MR 连通性或权限配置已验证。
- 无脚本样本没有执行 Docker 验证；原有验证接口通过专项测试，真实镜像运行、桌面安装包和生产环境未在本轮重放。
- 本轮未准备 Git push，因此按项目规则未运行完整 `pnpm test`；未执行 push 或部署。
