# 第三版范围与契约

依据用户确认的第三版方案，在第二版的只读本地工具上增加证据化审查。

| 已确认方案           | 目标对象                                           | 允许动作                                                               | 必须保持                                                                       |
| -------------------- | -------------------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 逐条审查关键判断     | 导读中的需求对照、分组修改前后、关键规则、流程步骤 | 人工记录已确认、有疑问、不成立及依据；导读或源码变化时标记旧记录待重核 | 分组级状态和旧快照仍可读；模型不替人确认                                       |
| 提高跨文件定位准确性 | 固定快照中已载入的 JS/TS 文本及变更声明            | 用现有 TypeScript Language Service 查找静态符号引用，展示对应变更      | 原有候选作为边界信息保留；不声称运行时可达，不读取当前仓库作为旧 commit 的源码 |
| 审查报告             | 当前固定快照、需求、导读及人工记录                 | 导出 Markdown，明确未分析、未对照、待重核和限制                        | 不自动宣告审查或测试通过，不修改被审查仓库                                     |

当前实现仅为本地个人工具，不接 GitHub/GitLab，也不执行被审查项目的测试。源码依据、用户填写的人工依据和实际运行证据是不同来源；报告按原样记录，不把人工输入升级为工具验证。
