## 保持的边界

- 被审查仓库只读；fixture 在工作区存在未提交修改时，快照仍对应指定 commit，Git 工作区状态保持一致。
- AI 结果先校验再保存；取消或无效结果不抹掉已有内容。
- 真实调用使用既有 ChatGPT 登录，没有 API Key 降级路径；本地笔记不发送给模型。
- 按当前开发约束，没有运行完整 `pnpm test`，没有 commit、push 或部署到公共环境。

## 尚未验证或不承诺

- 真实订阅耗尽、断网、超时和进程强杀未对在线服务做故障注入；HTTP 取消/失败测试不能替代全部 CLI 故障验证。
- 未做大型业务仓库性能评测、移动端专项验收及跨平台验收；本次环境为 macOS。
- 引用存在、结构有效及变更覆盖不代表业务解释正确。合成示例的成功也不保证所有项目的导读质量。
- 静态上下文收集的文件数、符号数及字符数受限，未建立完整运行时调用图；详细边界见 README。
